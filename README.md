Token Radar ranks pre-token crypto protocols by the implied value of a future token launch — computed from each protocol's TVL, seven-day growth and age with no token — and shows concrete steps to farm each one. It reads a sealed DefiLlama snapshot (758 protocols, 40 on the watchlist) and writes a 178-row ranked board plus a sortable, filterable dashboard with a detail view per protocol.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts --input /path/to/snapshot.json
```
